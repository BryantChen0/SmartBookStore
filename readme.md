# AI-Enabled Multimodal Smart Bookstore System

An AI-driven, multimodal smart bookstore application built with Python, Large Language Models (LLMs), Computer Vision, and Audio Processing. This document serves as the project overview and functional specification guide for developers.

## Project Overview

The objective of this project is to develop a desktop-based intelligent bookstore system powered by local AI capabilities. The system seamlessly integrates multimodal searching (text & images), local LLMs, Retrieval-Augmented Generation (RAG) for local bookstore knowledge, biometric authentication, and a robust rule-based user and financial management pipeline.

---

## User Roles & Access Control

The system defines four distinct user roles, each with increasing privileges:

| Role | Name | Login Requirement | Core Privileges & Differences |
| :--- | :--- | :--- | :--- |
| **VS** | Visitor | None | Browses catalog, searches books, views top global recommendations, interacts with general LLM chat. |
| **RC** | Registered Customer | Face / Voice | Maintains balance, receives personalized recommendations, leaves weighted reviews, eligible for VIP promotion. |
| **VC** | VIP Customer | Face / Voice | All RC privileges + automatic **10% discount** on all purchases. |
| **SU** | Super-User | Face / Voice | Highest privilege. Views store finance reports, adds new books via GUI, manages taboo word list, reopens suspended accounts. |

## Core System Requirements

### 1. Biometric Authentication
* **Multi-modal Login**: Users (RC, VC, SU) must authenticate using facial recognition or voice samples.
* **Technological Requirements**:
  * **Face Recognition**: A YOLO-based procedure to train and classify human faces.
  * **Voice Identification**: A short audio classifier for user identification.

### 2. Top 3 Book Recommendation Engine
* **Visitors (VS) & Super-Users (SU)**: Personalized features are disabled. Top page displays the **top 3 most purchased and browsed books** overall.
* **Registered (RC) & VIP Customers (VC)**: Shows personalized **top 3 recommendations** computed from their past browsing and purchasing history (evaluating author preference, category preference, and global popularity).

### 3. Multimodal Search & Catalog Browsing
* **Browsing**: Filter books by categories (e.g., Literature, Science), authors, or publishing dates.
* **Search**:
  * **Keyword Search**: Match text across book metadata or full texts.
  * **Multimodal Search**: Search by images (uploading cover pages or internal illustrations) using vision-language embeddings (e.g., CLIP).
* **Super-User GUI**: A simple GUI interface allowing the SU to add new books to the store.

### 4. RAG Chatbot & Privilege-Based AI Answers
* **Interactive Chat Box**: A text interface for user communication with the AI system.
* **Privilege Restrictions**:
  * Detailed store financial reports are **restricted strictly to Super-Users (SU)**.
  * Other user types querying financial or sensitive admin data receive restricted/empty responses.
* **Retrieval-Augmented Generation (RAG)**:
  * For queries about the store/team or local book content: system retrieves local context first and responds with the mandatory tag: **`(Generated via RAG)`**.
  * For general queries: delegates to the local LLM and responds with the mandatory tag: **`(Generated by LLM)`**.

### 5. Account Rules, Penalties & VIP Promotion
* **Account Balance**: RC and VC accounts maintain deposited funds.
* **Overdraft & Penalties**:
  * Making a purchase costing more than the account balance applies a **$1 fine**.
  * Any account with a negative balance is **suspended** (cannot log in).
  * Suspended accounts must ask the **SU** to reopen the account after depositing positive funds.
* **VIP Promotion**: An RC making **>3 purchases** or paying **>$200 in total** is automatically promoted to **VC** (granting a 10% discount).

### 6. Comment Moderation & Taboo Word Censorship
* **Ratings & Comments**: Users can leave 1-5 star ratings and written reviews. Reviews from buyers carry **higher weight**.
* **Dynamic Stock Lists**:
  * Books with **>3 ratings** and an average rating **< 2** are placed on the **No-Order List**.
  * Books with **>3 ratings** and an average rating **> 4** are placed on the **To-Order List**.
* **Censorship & Warnings**:
  * A **Taboo Word List** is maintained by the SU.
  * Any taboo word in a comment is replaced by `*`.
  * Comments containing **>3 taboo words** are blocked entirely.
  * Author of a blocked comment receives **1 warning**.
  * **2+ Warnings**: An RC account is **suspended**; a VC is **demoted to RC**.

## Key Architectural Decisions

1. **No External Database Required**: All user records, catalog metadata, indices, and financial logs are stored using local files (`JSON`, `.txt`, `.pkl`).
2. **Local & Free AI Stack**: Powered by **Ollama** for running local LLMs and embedding models. Zero paid APIs required.
3. **Local GUI System**: Built as a desktop application (PyQt / CustomTkinter), eliminating the need for complex web backend servers.
4. **Public Domain Catalog Data**: Seeded with free books downloaded from [Project Gutenberg](https://www.gutenberg.org/).
